# Daily Habit Tracker Application

## Description

This is a Windows Forms application built using C# in Visual Studio. This application helps users to organize their daily habits.

## Features

* User Login
* Navigation to the dashboard
* Add a new habit
* View all habits
* Complete habit
* Delete habit
* Monitor progress
* Logout

## Technologies used

* C#
* Windows Form
* Visual Studio
* .NET Framework

## Running the application

1. Clone the repository.
2. Open the .sln file using Visual Studio.
3. Compile the solution file.
4. Press F5 to run the program.
